# Stone Paper Scissors Game

A web-based version of the classic Stone, Paper, Scissors game built using HTML, CSS, and JavaScript.

## Features
* Interactive gameplay against a randomized computer opponent.
* Live scorecard tracking wins, losses, and ties.
* Instant status updates showing choices and results.
* Responsive design for desktop.

## Technologies Used
* HTML5
* CSS3
* JavaScript (ES6)

## How to Play
1. Click on Stone, Paper, or Scissors to make your move.
2. The computer will randomly select its counter-move.
3. The winner is determined, and the score updates immediately.

## Rules
* Stone beats Scissors.
* Paper beats Stone.
* Scissors beats Paper.
* Matching choices result in a tie.
